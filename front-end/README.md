# 🚀 The Complete Modern Frontend Engineering Masterclass
### *From Git Version Control to HTML5, CSS3, & Modern JavaScript (ES6+)*

Welcome to the **Complete Modern Frontend Engineering Masterclass**. This course is designed from the ground up for aspiring and practicing developers who want to master the core pillars of the web without relying on bloated libraries before understanding the fundamentals.

Every topic is explained in depth with conceptual explanations, architectural diagrams, real-world best practices, gotchas to avoid, runnable code examples, and production-ready portfolio projects.

## ⚡ How to Take This Course

1. **Sequential Progression**: If you are new to web development, proceed strictly in order from `00` through `05`. Version control is taught first because every single line of code you write should be tracked under source control.
2. **Code Along**: Do not simply read the code. Open the examples in your editor, change values, break things, inspect them with Chrome DevTools, and fix them.
3. **Run the Interactive Course Hub**:
   - Open [`index.html`](./index.html) in your browser (or use VS Code Live Server / `npx serve .`) to experience the interactive course portal.
4. **Complete the Practice Labs**: Every module contains practical challenges and code tasks to solidify your understanding.

## 🛠️ Required Prerequisites & Software

- **Computer**: macOS, Linux, or Windows (WSL2 recommended for Windows).
- **Code Editor**: Visual Studio Code (configured in `00-course-overview/02-developer-environment-setup.md`).
- **Terminal**: Bash, Zsh, or PowerShell.
- **Browser**: Google Chrome, Mozilla Firefox, or Brave (for DevTools).
- **Git**: Version 2.30 or newer.
