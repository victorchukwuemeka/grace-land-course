# Module 01: Version Control with Git

Git is the backbone of professional software development. You will learn the object model behind commits, then practice the workflows used by real teams.

## Lessons

| File | Topic |
| :--- | :--- |
| [`01-git-fundamentals.md`](./01-git-fundamentals.md) | Repositories, staging, commits, history, and the three trees. |
| [`02-branching-and-merging.md`](./02-branching-and-merging.md) | Branches, merges, rebases, and conflict resolution. |
| [`03-github-and-collaboration.md`](./03-github-and-collaboration.md) | Remotes, pull requests, reviews, and team workflows. |
| [`04-advanced-git-and-best-practices.md`](./04-advanced-git-and-best-practices.md) | Reflog, cherry-pick, bisect, stashing, and recovery. |
| [`git-cheatsheet.md`](./git-cheatsheet.md) | Commands you will use every day. |
| [`exercises/git-lab-simulation.md`](./exercises/git-lab-simulation.md) | A guided lab with real conflict scenarios. |

## Outcomes

- Explain what a commit actually contains.
- Create and merge branches without fear.
- Resolve conflicts deliberately.
- Collaborate through pull requests and code review.
- Recover from common Git mistakes.
