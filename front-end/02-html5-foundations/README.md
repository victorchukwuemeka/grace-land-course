# Module 02: HTML5 Foundations

HTML provides the structure and meaning of every page. This module covers document architecture, semantic elements, forms, validation, accessibility, and SEO.

## Lessons

| File | Topic |
| :--- | :--- |
| [`01-html-basics-and-syntax.md`](./01-html-basics-and-syntax.md) | Elements, attributes, document structure, text, lists, and media. |
| [`02-semantic-html-architecture.md`](./02-semantic-html-architecture.md) | Landmarks, sections, articles, headings, and accessible page structure. |
| [`03-forms-and-validation.md`](./03-forms-and-validation.md) | Form controls, input types, native validation, and accessible errors. |

## Outcomes

- Write a valid, production-ready HTML5 document.
- Choose semantic elements based on meaning, not appearance.
- Build accessible forms with labels, fieldsets, and validation.
- Structure headings and landmarks for screen readers and SEO.
- Avoid common HTML anti-patterns.
